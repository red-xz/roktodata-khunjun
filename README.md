# রক্তদাতা খুঁজুন — Find a Blood Donor (standalone web app)

কাছের রক্তদাতা, হাসপাতাল ও ডাক্তার খোঁজার অ্যাপ — Firebase Hosting-এ
ডিপ্লয় করা যাবে, আর Capacitor দিয়ে Android APK বানানো যাবে।
(Muse artifact থেকে ফিচার-স্পেক নিয়ে নতুন করে লেখা; artifact-এর
সোর্স পড়া হয়নি।)

## ফিচার (সবগুলো আছে)

- **ডোনার খোঁজা** — ব্লাড গ্রুপ দিয়ে, **কাছের ডোনার শুধু**: ১০ কিমি
  ডিফল্ট, ৫/২০/৫০ কিমিতে বাড়ানো যায়; কাছেরটা আগে; এক্স্যাক্ট গ্রুপ
  আগে, তারপর কমপ্যাটিবল গ্রুপ; দূরের ডোনার কখনো দেখায় না। এক চাপে কল।
- **ডোনার রেজিস্ট্রেশন** — নাম, ফোন, ঠিকানা, বয়স, জেন্ডার, গ্রুপ, পেশা
  + বাধ্যতামূলক সম্মতি "আমি স্বেচ্ছায় ফ্রিতে রক্তদান করতে আগ্রহী"
  (টিক না দিলে রেজিস্ট্রেশন হয় না — ফর্মে + Firestore rules-এ দুই
  জায়গায় এনফোর্স করা)। ছবি ঐচ্ছিক। নিজের তালিকা pause/edit/remove
  করা যায় (যে ডিভাইসে রেজিস্টার করেছে)।
- **হাসপাতাল + ডাক্তার খোঁজা** — একই কাছের-শুধু নিয়ম; রেজিস্টার্ড
  তালিকা আগে, তারপর OpenStreetMap/Nominatim থেকে আসল কাছের
  হাসপাতাল/ক্লিনিক/চেম্বার (দূরত্ব + কল + Google Maps directions লিংক)।
- **ডাক্তার রেজিস্ট্রেশন** — ডিগ্রি, বিশেষজ্ঞতা, বর্তমান কর্মস্থল,
  সরকারি/বেসরকারি, মেডিকেল রেজিস্ট্রেশন নম্বর, **ছবি বাধ্যতামূলক**।
- **হাসপাতাল রেজিস্ট্রেশন** — জায়গা, ফোন, সুবিধা/সেবা, যেসব ডাক্তার
  বসেন, **ছবি + লাইসেন্সের প্রমাণ বাধ্যতামূলক**। লাইসেন্সের কাগজ
  শুধু মালিকই দেখতে পারে (`hospitals/{id}/private/licence`, rules দিয়ে
  বন্ধ); পাবলিক শুধু "লাইসেন্স দেওয়া হয়েছে" ফ্ল্যাগ দেখে।
  কোনো অ্যাডমিন অনুমোদন ব্যবস্থা নেই।
- **সত্যির শর্ত** — হাসপাতাল + ডাক্তার রেজিস্ট্রেশনে বাধ্যতামূলক
  "আমার সকল তথ্য সত্যি" টিক (Firestore rules-এ `infoTrue == true`
  এনফোর্স করা; নতুন রেজিস্ট্রেশনে শুধু, এডিটে নয়)।
- **রিভিউ** — রেজিস্টার্ড হাসপাতাল/ডাক্তারে স্টার রেটিং + টেক্সট রিভিউ;
  গড় রেটিং কার্ডে দেখায়।
- **ব্লাড ব্যাংক ও সংগঠন** — Red Crescent, Quantum, Sandhani, BADHAN
  (কল + ওয়েবসাইট বাটনসহ)।
- **১২ ভাষা** — বাংলা + ইংরেজি সম্পূর্ণ; হিন্দি, উর্দু, আরবি (RTL),
  স্প্যানিশ, ফ্রেঞ্চ, পর্তুগিজ, ইন্দোনেশিয়ান, তুর্কি, রুশ, চীনা —
  মূল UI স্ট্রিং অনুবাদ করা, বাকিগুলোতে ইংরেজি fallback। দেশ বাছাই।
- **প্রফেশনাল ডিজাইন** — ডিপ নেভি + মেডিক্যাল রেড + টিল-গ্রিন,
  গাঢ় নেভি হেডার, পরিষ্কার সাদা কার্ড। লাইভ পরিসংখ্যান ব্যান্ড
  (মোট ডোনার, এখন প্রস্তুত, গ্রুপ কভারেজ — আসল ডেটা থেকে),
  গ্রুপ-টাইলে প্রস্তুত সংখ্যা + সবুজ ডট, কমপ্যাটিবিলিটি প্যানেল +
  পূর্ণ ৮×৮ চার্ট, "কীভাবে কাজ করে" ৩ ধাপ, যোগ্যতার চেকলিস্ট
  (বয়স ১৮–৭০, ৯০ দিনের বিশ্রাম)।
- **ফুটার** — প্রতি পেজে "© 2026 SOHEL. ALL RIGHTS RESERVED."।
  কপি-প্রতিরোধ: মূল কনটেন্টে রাইট-ক্লিক + টেক্সট সিলেকশন বন্ধ

## ডেটা মডেল (Firestore)

```
donors/{id}            name, phone, address, age, gender, bloodGroup,
                       profession, photoUrl?, lastDonation?, lat, lng,
                       district, country, paused, voluntaryFreeConsent,
                       ownerUid, ownerToken, createdAt, updatedAt
hospitals/{id}         name, phone, address, facilities, doctorsHere,
                       photoUrl, licenceProvided, lat, lng, district,
                       country, infoTrue, ownerUid, ownerToken, createdAt
hospitals/{id}/private/licence   { dataUrl } — শুধু মালিক পড়তে পারে
doctors/{id}           name, phone, degree, specialty, workplace,
                       workplaceType, regNumber?, photoUrl, address,
                       lat, lng, district, country, infoTrue,
                       ownerUid, ownerToken, createdAt
reviews/{id}           targetType, targetId, stars, text, name,
                       ownerUid, createdAt
blood_orgs/{id}        (ভবিষ্যতে Firestore থেকে সংগঠন যোগ করলে)
takedowns/{phone}      { phone } — সিড-ডোনার সরানোর অনুরোধ
```

**মালিক-স্কোপিং (শপ অ্যাপের কোড-কি পদ্ধতির বদলে):** শপ অ্যাপে শপ কোডই
অ্যাক্সেসের চাবি ছিল। এই অ্যাপে পাবলিক তালিকা — তাই পড়া সবার জন্য
খোলা (অ্যানোনিমাস লগইন থাকলে), আর লেখা মালিক-স্কোপড: প্রতিটা
ডকুমেন্টে `ownerUid` (অ্যানোনিমাস Auth UID) থাকে; rules শুধু মালিককে
update/delete দিতে দেয়। `ownerToken` (localStorage-এ র‍্যান্ডম টোকেন)
অ্যাপের ভেতরে "আমার তালিকা" চেনার জন্য — rules UID দিয়েই যাচাই করে।
অ্যানোনিমাস UID একই ব্রাউজারে স্থায়ী থাকে; ব্রাউজার ডেটা মুছলে বা
নতুন ডিভাইসে মালিকানা হারাবে (এটা অ্যানোনিমাস মডেলের সীমা — ভবিষ্যতে
ফোন-OTP লগইন যোগ করলে মালিকানা ফোন নম্বরে বাঁধা যাবে)।

**ছবি:** Firebase Storage ব্যবহার করা হয়নি (সেটআপ সহজ রাখতে)।

হিসেবে ডকুমেন্টে থাকে — Firestore-এর ১MB ডকুমেন্ট সীমার ভেতরে।
স্কেল বাড়লে Storage-এ নেওয়া উচিত।

**খোঁজার লজিক:** Firestore থেকে পুরো কালেকশন এনে ক্লায়েন্টে ফিল্টার
করা হয় (এই স্কেলে শত শত ডকুমেন্ট — composite index লাগে না)।
দূরত্ব haversine দিয়ে; কোঅর্ডিনেট না থাকলে জেলা-কেন্দ্র ফলব্যাক
(আনুমানিক — কার্ডে দূরত্ব জেলা-কেন্দ্র থেকে দেখায়)।

## Firebase setup checklist (parent-এর জন্য)

1. **Firebase Console-এ নতুন প্রজেক্ট** খুলুন (পরামর্শ: ID
   `roktodata-khunjun` — খালি থাকলে; না হলে কাছাকাছি কিছু)।
   Spark (ফ্রি) প্ল্যান যথেষ্ট শুরুতে।
2. **Authentication → Sign-in method → Anonymous → Enable** করুন।
3. **Firestore Database → Create database** — Production mode,
   লোকেশন `asia-southeast1` (সিঙ্গাপুর — বাংলাদেশের কাছের)।
4. **Hosting** — Get started (সাইট ID প্রজেক্ট ID-এর মতোই হবে)।
5. **Project Settings → Your apps → Web app (</>)** যোগ করুন —
   সেখান থেকে `firebaseConfig` অবজেক্টের ৬টি মান নিয়ে
   `firebase-config.js`-এ `REPLACE_ME`-গুলোর জায়গায় বসান:
   `apiKey`, `authDomain`, `projectId`, `storageBucket`,
   `messagingSenderId`, `appId`।
6. **Firestore rules ডিপ্লয়** — `firestore.rules` ফাইলটি
   (CLI-তে `firebase deploy --only firestore:rules`, অথবা শপ অ্যাপের
   মতো Rules REST API — `~/workspace/shop-app-deploy/deploy-rules.js`
   প্যাটার্ন দেখুন; service account key লাগবে)।
7. **Hosting ডিপ্লয়** — `firebase deploy --only hosting`
   (sandbox থেকে করলে `~/AGENTS.md`-এর Firebase অংশের gotcha দেখুন:
   global-agent + NODE_OPTIONS, service-account key, configstore
   chown EPERM কসমেটিক)।
8. যাচাই: লাইভ URL খুলে একজন ডোনার রেজিস্টার করে দেখুন + খোঁজা চলে
   কি না দেখুন।

**মনে রাখবেন:** `firebase-config.js` প্লেসহোল্ডার থাকা অবস্থায় অ্যাপ
চলে (সিড-ডেটা দিয়ে খোঁজা যায়), কিন্তু রেজিস্ট্রেশন/রিভিউ সংরক্ষণ
হয় না — উপরে সতর্কবার্তা দেখাবে।
